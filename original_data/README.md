# Original Data

This directory stores archived raw data snapshots used by the reproducible scripts.

## Source

- Platform: Zhihu
- Crawled: December 2024
- Source URL: https://www.zhihu.com/question/668753879/answer/3649938067

## Expected Files

- `zhihunw_new.xlsx`: network-oriented raw answer data with liker lists.
- `zhihu_sen_new.xlsx`: labeling-oriented raw answer data.
- `cleaned_data.xlsx`: cleaned legacy answer-text data, used as fallback/reference.
- Other `.txt` files: legacy dictionaries or raw auxiliary files retained for provenance.

These files are ignored by git. Keep them local and do not overwrite the archived originals.
